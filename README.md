# Kids pocket money

Read-only page showing Sky's and Noam's pocket money balances.

- Data comes from the **Balances** tab of the "Kids pocket money" Google Sheet, published to the web as CSV (`CSV_URL` in `index.html`).
- The page refreshes every 5 minutes and whenever it is reopened.
- `?kid=sky` or `?kid=noam` shows a single kid. `?demo` shows sample numbers.

Served by GitHub Pages from the `main` branch.
